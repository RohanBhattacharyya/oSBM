# Contributor credits

When accepting an oSBM contribution, update the Credits dialog in
`source/application/mobile/StarMobilePlatform.cpp` and its launcher translations
under `source/application/mobile/android/host/app/src/main/assets/lang/`.
Credit code, localization, art and design contributions. Keep the oSBM list
separate from the upstream OpenStarbound acknowledgment. Preserve existing
credits when replacing or redesigning a feature.

Current oSBM credits:

- Rohan Bhattacharyya: creator and maintainer.
- Sunbrella114514: localization support and language exposure.
- lotigara (Ivan Davydov): Linux ARM support.
- Ballefroide: revamped touch controls artwork and design, supplied in
  [issue #65](https://github.com/RohanBhattacharyya/oSBM/issues/65).

The original sprite archive is linked from that issue. Files in
`assets/osbm/controls/` retain the artist's original names and image data.
