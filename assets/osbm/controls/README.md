# Touch controls artwork

Artwork and control design by **Ballefroide**, supplied for oSBM in
https://github.com/RohanBhattacharyya/oSBM/issues/65.

Original archive: https://www.mediafire.com/file/rd996p6zhovuzot/osbm_buttons.zip/file

The PNG files are unchanged from the supplied archive. `(1)` and `(2)` are
normal and pressed variants. The additional `(3)` shift variant is preserved.
